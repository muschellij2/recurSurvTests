# Plot recurrent-survival confidence intervals or bands

Plot recurrent-survival confidence intervals or bands

## Usage

``` r
plot_recurrent_surv_ci(x, ...)
```

## Arguments

- x:

  Object returned by
  [`recurrent_surv_ci()`](https://muschellij2.github.io/recurSurvTests/reference/recurrent_surv_ci.md).

- ...:

  Passed to [`plot()`](https://rdrr.io/r/graphics/plot.default.html).

## Value

Invisibly returns `x`.
